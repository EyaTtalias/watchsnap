📸 Screenshot Instructions

  1. Open each ad by clicking the button above — it opens in a new browser tab
  2. Open DevTools (F12 or Cmd+Opt+I) → click the Toggle Device Toolbar icon (phone icon)
  3. Set a custom size: Width: 1080 · Height: 1080 · DPR: 2 for retina quality
  4. Take a full-page screenshot: DevTools → three-dot menu → Capture screenshot
  5. Save as .PNG — do NOT use JPG for ad uploads (quality loss)
  6. Upload directly to Facebook Ads Manager or Instagram as a Feed image post
💡 Pro tip: In Chrome DevTools, you can use Ctrl+Shift+P (Cmd+Shift+P on Mac) and type "screenshot" to access "Capture full size screenshot" which captures the entire canvas at high resolution — no cropping needed.
