📸 How to Export Each Ad as 1080×1080 PNG

  1. Click "Open Ad" — each page is pre-sized at exactly 1080×1080px
  2. In Chrome: open DevTools (F12) → Toggle Device Toolbar → set custom size 1080 × 1080
  3. Press Ctrl+Shift+P → type "Capture screenshot" → select "Capture full size screenshot"
  4. Save as .PNG — avoid JPG (gradient quality loss)
  5. Upload to Facebook Ads Manager as a Single Image Ad at 1:1 ratio
  6. Set destination URL to watchsnap.vercel.app and CTA button to match each ad's copy
💡 Pro tip: Run A/B tests — pit Ad 1 (fear/scam) vs Ad 3 (emotional/inheritance) at identical budgets. The fear-based ad typically wins on CTR; the emotional ad often wins on conversion quality. Test both audiences: "Watch Collectors" interest + "Luxury Goods" interest targeting.
