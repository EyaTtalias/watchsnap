📝 Ad Copy File

All 5 Facebook ad stories, headlines, descriptions, CTA copy and hashtags are in ad-copy.txt. Open the file, copy the relevant block for each ad, and paste directly into Facebook Ads Manager under "Primary Text" and "Headline" fields.

📸 Export Each Ad as 1080×1080 PNG

  1. Click "Open Image →" to open the ad (pre-sized at 1080×1080px)
  2. Chrome DevTools (F12) → Toggle Device Toolbar → set 1080 × 1080
  3. Ctrl+Shift+P → type "Capture screenshot" → "Capture full size screenshot"
  4. Save as .PNG — never JPG (gradient quality loss)
  5. In Facebook Ads Manager: create Single Image Ad → upload PNG → 1:1 format
  6. Paste story text from ad-copy.txt into Primary Text field
  7. Set destination URL: watchsnap.vercel.app
💡 A/B Testing tip: Start with Ad 1 (fear/loss) vs Ad 3 (emotional/heirloom) at identical budgets — $20/day each. These two angles consistently win on CTR vs value or ROI ads. Scale the winner after 5 days. Then test Ad 5 (ROI) separately to a Dealer / Collector audience.
