📸 How to Screenshot Each Slide

  1. Open any slide by clicking "Open →" — it opens at exactly 1080px wide
  2. In Chrome: open DevTools (F12) → Toggle Device Toolbar → set 1080 × 1080
  3. Press Ctrl+Shift+P → type "Capture screenshot" → select "Capture full size screenshot"
  4. Save as .PNG — do not use JPG (quality loss on gradients)
  5. Upload all slides for one carousel as a Facebook Carousel Ad in Ads Manager
  6. Set each slide's CTA to link to watchsnap.vercel.app
💡 Facebook Carousel tip: Upload slides in order (1→4). Facebook shows them left-to-right, so the story flows naturally as users swipe. Add the CTA button "Learn More" or "Try Now" pointing to watchsnap.vercel.app on each card.
